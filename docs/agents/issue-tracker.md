# Issue tracker: GitHub

Project specifications and tickets live in GitHub Issues for `BuhDuy256/crypto-strategy-lab`. Use the `gh` CLI from this repository so it resolves the configured remote automatically.

## Conventions

- Read issues with `gh issue view <number> --comments` and list them with `gh issue list`.
- Create, edit, comment on, label, or close issues only when the user explicitly requests the corresponding external write.
- When a skill says to publish a specification or ticket, create a GitHub issue after the skill's required draft review or confirmation.
- Pull requests are not a request or triage surface for this project.

## Labels

The `triage` skill is not installed, so no triage label vocabulary was created. Do not invent or create labels. If a workflow requires a label such as `ready-for-agent`, use it only when it already exists and the user explicitly requests the issue update; otherwise pause and ask.
